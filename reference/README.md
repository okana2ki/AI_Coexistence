# 参考文献

ここには、実在を確認した資料だけを置きます。最初から結論を支える文献だけを集めず、利点、リスク、教育、社会制度など異なる観点を探してください。

## 収録PDF

[鶴田ほか 2023 生成AI依存傾向尺度](鶴田ほか_2023_生成AI依存傾向尺度.pdf)

- 書誌情報: 鶴田利郎・石川久美子・田中博之（2023）「高校生・大学生向け生成AI依存傾向測定尺度の開発」『AI時代の教育論文誌』6, 40-45.
- DOI: [10.50948/esae.6.0_40](https://doi.org/10.50948/esae.6.0_40)
- 資料種別: 査読付き原著論文、オープンアクセス
- 使える問い: 生成AIへの依存傾向をどのような下位概念で捉えられるか。
- 注意: 尺度が測るのは著者が定義した依存「傾向」であり、医学的診断ではありません。別の集団で使う場合は妥当性や実施倫理を再検討します。

## 使い方

1. [文献リスト](文献リスト.md)から研究問いに関係する資料を選ぶ。
2. リンク先で題名、著者、年、本文を確認する。
3. `guide/templates/根拠カードテンプレート.md`を`work/`へコピーする。
4. 主張、該当箇所、限界、自分たちの問いとの関係を自分の言葉で記録する。

リンクの確認日は2026年9月14日です。公開状況や最新版は変わるため、使用前に再確認してください。
