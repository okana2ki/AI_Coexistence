# この「AIエージェント体験演習」のねらい

1. **最新のAI（AIエージェント）を体験**することは、AIと人間の共生について考えるためにの出発点として必須。最新のAIを知らずにAIと人間の共生のしかたを提案しても多くの場合的外れになるだろう。
2. **AIエージェント**を研究のパートナーとして使うことにより、**研究成果の質を上げる**（研究の問を深める；調査の質を高める；考察を深める）。
3. 一般的には、AIエージェントを使うことで研究の効率の向上と質の向上が期待できるが、皆さんは学生で、勉強して力をつける段階であるため、効率の向上よりも**力をつける使い方**をすることを重視する。

# AIと研究する前に

効率の向上でなく、皆さんの力をつけるという目的を達成するため、このプロジェクトで体験するのは、AIに研究を任せることではない。AIが出した候補を材料にして、皆さんが問いを立て、調べ、話し合い、判断する。

## 人とAIの分担

| 学生が担うこと | AIに頼めること |
| --- | --- |
| 何を重要だと考えるか | 問いの候補を整理する |
| 研究上の問いを選ぶ | 問いが広すぎないか点検する |
| アンケート調査への同意を得る | 調査票の曖昧な表現を指摘する |
| 文献等の証拠の質を判断する | 検索語や関連分野を提案する |
| 調査結果や分析結果を解釈する | 別解釈や反対証拠を挙げる |
| 結論と発表に責任を持つ | 構成や分かりにくい箇所を批評する |

AIは、もっともらしい誤りや存在しない出典を出すことがあります。流暢さと正しさは別です。AIの答えを採用する前に、チームの誰が、何を使って確認したかを記録してください。

## 最初の合意

チームで次を決めて`work/意思決定ログ.md`に残します。

- この研究で自分たちが知りたいこと
- AIに任せてよい作業と、任せない作業
- 発言しやすい話し合いの方法
- 文献や数値を確認する担当
- 判断が割れたときの決め方
- 担当教員へ相談する条件

高校生と大学生の役割を固定しないでください。学年ではなく、関心と得意分野を基に分担し、重要な判断には全員が参加します。
