# 学生チームへの配布前チェック

この文書は担当教員・運営者向けです。班ごとにワークスペースを複製する直前に確認してください。

## 配布物

- [ ] `README.md`と`AGENTS.md`がルートにある。
- [ ] `guide/`、`reference/`、`submission/`、`work/`がある。
- [ ] `submission/`には架空チームの教材だけがある。
- [ ] `work/`に他班や過年度の記録が残っていない。

## 個人情報と権利

- [ ] ファイル名、本文、コメント、変更履歴、文書プロパティを確認した。
- [ ] 氏名、連絡先、学籍番号、成績、顔写真、相談内容が残っていない。
- [ ] 参考PDFの再配布条件を確認した。リンクだけにする必要がある資料はファイルを入れない。
- [ ] 学校・大学・発表会の生成AI利用規則を学生へ示した。

## 無料利用

- [ ] 学生にはChatGPT無料プランでのサインインを案内する。
- [ ] APIキーを入力させない。API利用は従量課金であることを説明する。
- [ ] 無料枠の上限、利用可能な機能、対応OSを公式ページで当日に再確認する。
- [ ] 無料枠に達した場合の代替として、チーム内レビューと通常の文献検索手順を用意する。

## 最初の授業

1. AIに入力してよい情報と、入力しない情報を確認する。
2. 架空提出物を人だけで5分評価する。
3. 同じ提出物をCodexに評価させる。
4. 人の評価とAIの評価の違いを話し合う。
5. AIの助言を一つ採用し、一つ不採用にして理由を記録する。

この順番にすると、学生は最初からAIの答えを正解として受け取らず、比較して判断する役割を体験できます。
