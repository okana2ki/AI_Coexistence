# Codex導入ガイド

## 無料で始める

OpenAIの公式料金ページでは、CodexはChatGPT Freeプランに含まれ、無料枠は月額0ドルと案内されています。利用上限は作業の大きさ、モデル、実行場所などで変わるため、表示された残量や制限をその都度確認してください。

### 開始手順

1. [公式クイックスタート](https://learn.chatgpt.com/ja-JP/docs/quickstart)に沿って**ChatGPTデスクトップアプリをインストール**
    > 2026年9月時点では、ウェブ版ChatGPTではフォルダを作業場所として指定できないユーザが多いと思われるため、ChatGPTデスクトップアプリをインストールする必要がある。デスクトップアプリではCodexを使うことができ、Codexにおいてはフォルダを作業場所として指定できる。
1. アプリを開き、自分のChatGPTアカウントでサインイン
1. 左上のメニュー(`ChatGPT`/`Codex` の切り替え)から`Codex`を選択
1. Codex の権限の設定
    > 画面上部メニューから「編集」をクリック(または、画面左下隅のプロフィールアイコンをクリック)→ドロップダウンメニューから「設定」をクリック→「一般」の「権限」に2つのトグルスイッチがあります。慣れるまでは、「デフォルト権限」だけ ON、**「フルアクセス」は OFF**、と設定しておくのが安全です。

    > 「設定」をクリック→「構成」をクリック→「エージェントのデフォルト」中の「承認ポリシー」と「サンドボックス設定」を選択。慣れるまでは、「承認ポリシー」は「リクエスト時」、「サンドボックス設定」は「読み取り専用」が適切だと思います。少し慣れてきたら「サンドボックス設定」を「ワークスペース内での書き込み」にするとよいでしょう。
1. 左カラムメニューの`プロジェクト`にマウスオンして、現れた`＋`をクリックし、新規プロジェクトを作成
1. プロジェクト名を適宜入力（例：AIと人間の共生）
1. ソースフォルダとして、`AI_Coexistence`を追加
    > [このWebページ](https://sites.google.com/view/genai4e/%E3%82%A4%E3%83%99%E3%83%B3%E3%83%88/codex2#h.7gfztedtamxf)から圧縮ファイル（zipファイル）をダウンロードし、それを解凍したフォルダ`AI_Coexistence`をPCの適切な場所（C:の直下など、できるだけ浅い階層が望ましい）に置き、それをソースフォルダとして追加して下さい。

    > この演習では、ソースフォルダ内のファイルをAIに読み書きさせます。
1. `プロジェクトを作成`をクリック
1. 左側カラムのメニューから`新しいチャット`をクリック
1. 対話窓の左上部の`プロジェクトを選択`をクリックして、先ほど作成したプロジェクトを選択（左上部に別のプロジェクト名が表示されているときは、それをクリックして、先ほど作成したプロジェクトを選択し直す；初めから所望のプロジェクト名が表示されている場合は、何もせずに次に進む）
1. 動作確認のため最初のメッセージ（下記）を送る。
    > `README.md`と`AGENTS.md`を読み、このワークスペースでのあなたの役割、してよいこと、してはいけないことを説明してください。ファイルはまだ変更しないでください。
1. 動作確認のための2番目のメッセージ（下記）を送る。無料枠を温存したいときはこのステップは省略可。
    > `work`フォルダに、1 から 10 までの合計を計算して表示する簡単な Python プログラムを作成し、実際に実行してください。

    `55` と表示されれば、Codex から Python プログラムを作成・実行できるところまで確認できています。この Python の実行の過程で、標準的な設定であれば、次のようなメッセージが表示されると思います。`通常の python コマンドが未登録だったため、Codex に同梱された Python 実行環境を確認して再実行します。` 今回の例のような簡単な Python 実行は Codex 同梱の環境で実行できるので、PC 側の Python を実行する権限を Codex に与える必要はありません。PC 側 Python にだけ入っているライブラリや仮想環境を使う場合など、PC 側 Python が必要になったときだけ、コマンド単位で許可する運用がお勧めです。特に重要なのは、「Python に権限を与える」ことは、実質的に「Python が実行する任意のコードに権限を与える」ことだという点です。そのため、python.exe を無条件・恒久的に許可するより、実行するコマンドを毎回確認する方が安全です。
1. 画面左下のユーザ名をクリック→"残り使用量"をクリック→残り使用量を確認

## 課金を避けるための確認

- ChatGPTアカウントでサインインする。APIキーでのサインインは従量課金用なので使わない。
- 有料プランへの変更、クレジット購入、外部有料サービスへの登録を行わない。
- アプリに課金確認が出たら進めず、担当教員に相談する。
- 無料枠を節約するため、一度に「研究全部」を頼まず、評価、検索語、反対意見など小さな目的に分けて頼む。

## Codexに見せてよいもの

授業用に公開してよい資料、匿名化した自作メモ、公開済み文献は扱えます。氏名、連絡先、学籍番号、顔写真、成績、健康や家庭に関する情報、未公開の相談内容、パスワードは入力しません。

## うまくいかないとき

- 指示が伝わらない: 目的、対象ファイル、してほしいこと、してほしくないこと、出力形式を書く。
- 応答が長すぎる: 「まず問題点を3つ」「表ではなく短い箇条書き」など範囲を狭める。
- 出典が怪しい: DOIや公式URLを求め、自分でリンク先を開いて確認する。
- 勝手に書き換えそう: 「ファイルは変更せず、提案だけ」と明記する。
- 無料枠の上限に達した: 作業記録をつけ、枠のリセット後（5時間後）に続ける。有料枠への変更はしない。

次のいずれかに該当する場合は、できるだけ講習前に生成 AI などで対処方法を尋ねて対処しておいてください。ChatGPT デスクトップアプリのような新しいツール、ここ数か月以内に仕様変更されたツールは日本語ドキュメントが未整備のことが多く、Web 上の解説記事も以前の仕様の時点のもので不適切であることが多いため、生成 AI に尋ねるのが手っ取り早いです。ただし、新しいツールについての情報は生成 AI の事前学習の時点には無かった、あるいは、旧仕様であったこと
が想定されるので、生成 AI には、公式ドキュメントを検索することにより、最新情報に基づいて答えてもらうことが必要になります。
- ChatGPT デスクトップアプリをインストールできない
- ChatGPT にログインできない
- Codex が表示されない
- Codex から PC 上のフォルダを開けない
- `README.md` 等の内容を Codex が読み取れない
- Codex から Python を実行できない

参照: [OpenAI公式料金](https://learn.chatgpt.com/ja-JP/docs/pricing)、[認証方法](https://learn.chatgpt.com/ja-JP/docs/auth)、[AGENTS.mdの説明](https://learn.chatgpt.com/ja-JP/docs/agent-configuration/agents-md)。機能と条件は変更されることがあります。
