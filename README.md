# AIと人間の共生 研究ワークスペース

このワークスペースは、高校生と大学生がCodexの支援を受けながら、自分たちで研究を進めるための練習用環境です。AIは、問いの候補を比べる、提出物の弱点を見つける、文献検索を助ける、計画を具体化するといった仕事を支援します。問いを決め、証拠を評価し、価値判断を行い、発表内容に責任を持つのはチームです。

## 最初の30分

1. [はじめに](guide/00_はじめに.md)を全員で読む。
2. [Codex導入ガイド](guide/01_Codex導入.md)に沿って、ChatGPT無料プランでCodexを開く。
3. Codexに「このワークスペースの目的と、あなたがしてはいけないことを説明して」と尋ね、`AGENTS.md`が反映されていることを確認する。
4. [架空の中間報告](submission/架空チーム青空_中間報告.md)を読んで、「評価基準に沿って、直すべき点を優先順に3つ挙げて」と依頼する。
5. 自分たちの作業は`work/`で始め、完成して合意した版だけを`submission/`へ移す。

## フォルダ構成

| フォルダ | 用途 |
| --- | --- |
| `guide/` | 導入、研究手順、プロンプト例、評価基準、安全上のルール |
| `project_description/` | プロジェクト全体の企画解説、提出物の指示 |
| `reference/` | 実在する文献、公式資料、検索の起点 |
| `work/` | 問い、検索ログ、根拠カード、AI利用記録などの作業中ファイル |
| `submission/` | 中間報告・最終発表など、チームが提出すると決めた版 |

`work/`と`submission/`を分けたのは、考え途中の記録と提出版を混ぜないためです。AIの提案をそのまま提出物にしない仕組みにもなります。

## このワークスペースの基本原則

- AIの出力は「候補」であり、根拠ではない。
- AIが示した文献は、表題、著者、年、URLまたはDOI、本文の該当箇所を人が確認する。
- 架空の数値、存在しない文献、確認できない引用を研究結果に使わない。
- 個人情報、未公開の相談内容、顔写真、成績、健康情報を入力しない。
- アンケートやインタビューは、実施前に担当教員の承認を得る。
- AIの利用箇所と、人がどう判断・修正したかを記録する。

## 迷ったときの最初の依頼

> 私たちは高校生と大学生の混合チームで、「AIと人間の共生」を研究しています。まずREADME.mdとAGENTS.md、guide/の資料を読み、現在のファイルを変更せずに、次に行うべき作業を3つ提案してください。各提案について、学生が決めることも示してください。

公式情報や料金・機能は変わるため、Codexの利用条件は[OpenAI公式の料金ページ](https://learn.chatgpt.com/docs/pricing)と[クイックスタート](https://learn.chatgpt.com/docs/quickstart)で都度確認してください。
