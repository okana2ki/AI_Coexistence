# 提出物サンプル

ここにある「架空チーム青空」の資料は、Codexによる評価と改善提案を体験するための教材です。チーム、参加者、記録、数値はすべて架空で、実際の調査結果ではありません。学術的事実として引用しないでください。

サンプルには意図的に改善余地を残しています。特に、問いの範囲、少人数データの一般化、評価基準、反対証拠、倫理手続きが十分かを検討してください。

## 練習手順

1. [中間報告](架空チーム青空_中間報告.md)を読む。
2. [根拠カード](架空チーム青空_根拠カード.md)と[AI利用記録](架空チーム青空_AI利用記録.md)を照合する。
3. Codexに`guide/04_提出物評価基準.md`での評価を依頼する。
4. AIの指摘をそのまま採用せず、チームで優先順位を決める。
5. 改善案を`work/中間報告_改善案.md`として作る。
