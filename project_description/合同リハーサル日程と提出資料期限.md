# 合同リハーサル

日時：令和8年10月10日（土）10:30～12:00

場所：５２０２号教室

出席者：A班・B班・C班・D班の大学生メンバー、高校生メンバー、メンター教員、関係者

各班の発表持ち時間は10月15日の本番と同じ10分ずつです。

# 提出資料と期限

合同リハーサル用の提出資料の期限は、10月7日（水）とします。

各班は、10月7日（水）までに、以下の資料を提出・共有できるよう準備してください。

1. 本番用発表スライド
2. 最終報告書または報告要旨
3. 根拠カード
4. AI利用記録
5. 発表原稿または発表分担表
6. 想定質問と回答案
7. 高校生メンバーの意見を反映した箇所の整理

10月10日の合同リハーサルでは、新たに内容を作るのではなく、10月15日の本番を想定して、
発表時間、発表順、話し方、スライドの見やすさ、根拠の示し方、AI利用の説明、質疑応答への対応を確認します。

特に、各班は中間合同報告会での助言を踏まえ、次の点を意識して資料を仕上げてください。

- 「調べたこと」の紹介だけで終わらず、自分たちの結論・提案を明確にすること
- AIの回答をそのまま使うのではなく、AIをどのように使い、人間がどこを判断・修正したかを説明すること
- 根拠カードや出典確認を整理し、発表で使う根拠を明確にすること
- 高校生メンバーの視点を、発表内容の分かりやすさや現場感の補強に反映すること
- 10月15日の発表が、4班全体として「AIと人間の共生」を多面的に示す内容になるよう意識すること

10月10日のリハーサル後に修正が必要になった場合は、
班ごとにメンターの先生と相談しながら、個別に最終調整を行ってください。

各班の班長は、10月7日（水）までの提出に向けて、
班内の作業分担、スライド作成、発表者確認、高校生メンバーとの連絡を進めてください。

10月15日の本番では、AIの答えを発表するのではなく、
「AIも活用しながら、私たちはこう考えました」と、自分たちの言葉で発表できることを期待しています。
