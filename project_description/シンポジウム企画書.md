# 全体テーマ
AIと人間の共生――総取り型AI社会を超えて、若い世代が希望をもって共創するための対話力・創造力・責任設計

生成AIをはじめとする人工知能技術が若い世代の学び、仕事、創造、生活、地域社会に与える影響を、学生自身の研究発表を通じて考察するものである。
単なるAIの技術紹介ではなく、AIを人間の可能性を広げるパートナーとして位置づけ、若い世代がAIと主体的・責任的に共生するための対話力、創造力、責任設計を考えることを狙いとする。

# 4班のテーマの方向性
| テーマ | 検討の必要性 | 検討の方向性 | 想定される結論の軸 |
| --- | --- | --- | --- |
| A班：AIと人間の役割分担 | AIは情報整理、文章作成、分析、提案などを急速に高度化しているため、AIに任せることと人間が担うことを明確にする必要がある。 | 大学生活、企業活動、地域課題の場面において、AIが得意な作業と人間が担う判断・責任を整理する。 | AIは作業・整理・比較を支援し、人間は問いの設定、価値判断、責任、信頼形成を担う。 |
| B班：AIと感性・創造性 | AIは文章、画像、企画、音楽、デザインなど創造的分野にも関わり始めており、創造性を広げる面と画一化する面を検討する必要がある。 | 人間のみ、AIのみ、人間＋AIの創作実験を比較し、独自性、共感性、宮崎らしさ等を評価する。 | AIは発想や試作を加速するが、意味づけ、選択、共感、地域性は人間が担う。 |
| C班：AIと倫理・責任の所在 | AI利用の拡大に伴い、誤情報、個人情報、著作権、差別、依存、判断ミス等の問題が生じるため、責任の所在を整理する必要がある。 | レポート作成、個人情報入力、誤った助言、偏った判断、AI相談等の事例から責任分担を検討する。 | AIは責任を負えない。利用者、教育機関、提供者、社会制度が責任を分担し、学生は利用開示・検証・個人情報保護を徹底する。 |
| D班：AIと生活スタイルの変化 | AIは学習、仕事、買い物、健康管理、相談、地域生活、防災、行政サービスなど日常生活全体を変えつつある。 | 学生生活、家庭生活、地域生活、宮崎の観光・農業・福祉・防災等の場面でAI活用とリスクを整理する。 | AI共生型生活とは、生活をAIに丸投げすることではなく、AIで生まれた時間や能力を学び、人間関係、地域参加、自立に活かすことである。 |

# AI利用・相談・記録の共通ルール
| ルール | 内容 |
| --- | --- |
| AIに結論を作らせない | AIは下書き、発想、比較、反論、整理に使う。最終結論は班の議論で決める。 |
| 個人情報を入力しない | 氏名、学籍番号、成績、健康、家庭事情、相談内容、未公開資料等を個人向け生成AIへ入力しない。 |
| 出典を確認する | AIの回答は、文献、新聞、政府・大学資料、一次情報で確認する。 |
| AI利用記録を残す | 使用AI、質問、回答、利用箇所、人間の修正、出典確認を記録する。 |
| 相談はメンター経由 | AIアドバイザーへの相談は、原則として班メンターを通じて行う。 |
| AI実験は条件をそろえる | 複数のAIや複数の条件を比較する場合、プロンプト、入力条件、評価基準を記録する。 |
| 学生の言葉で発表する | AIの文章をそのまま読ませず、学生自身が理解し、自分の言葉で説明できる内容にする。 |
